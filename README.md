# KamiDrop 紙

Легкий локальний друк на мережеві принтери з Android — «як AirPrint»: без драйверів, акаунтів і хмари.
Принтер знаходиться сам через mDNS, друк іде по IPP в AirPrint-растрі (`image/urf`).

## Що вміє

- сам знаходить принтери в Wi-Fi мережі й пам'ятає їх; можна додати й за IP-адресою;
- показує стан принтера, колір/дуплекс/роздільність і рівні чорнила чи тонера;
- друкує PDF і фото: превʼю, вибір сторінок, колір, двосторонній друк, копії, скасування;
- редактор макета: орієнтація, вписати / заповнити / 100 %, фото 9×13, 10×15, 13×18, A5 з кадруванням,
  поля або друк «до краю» на принтерах, що це вміють;
- кілька фото на аркуші: тягни, масштабуй, повертай — розміри на папері ті самі, що на екрані;
- «Поділитися → KamiDrop» з галереї, файлів чи будь-якого застосунку;
- сам повідомляє про нові версії й оновлюється з цих релізів.

Потрібен принтер із підтримкою AirPrint (більшість мережевих принтерів після ~2013 року),
телефон з Android 7+ у тій самій Wi-Fi мережі.

## Встановлення

1. Завантаж APK з [останнього релізу](https://github.com/4bit33/kamidrop/releases/latest):
   `kamidrop-…-arm64-v8a.apk` — для майже всіх сучасних телефонів.
2. Відкрий файл на телефоні. Android попросить дозволити встановлення з цього джерела —
   дозволь. Якщо Play Protect попередить про невідомого розробника — «Усе одно встановити».
3. Далі KamiDrop сам підкаже, коли вийде нова версія.

## Збирання

Потрібен [Flutter](https://flutter.dev) (stable) і Android SDK.

```
flutter pub get
flutter test
flutter run                                   # на під'єднаний телефон
flutter build apk --release --split-per-abi   # release-APK
```

Release підписується ключем з `android/key.properties` (не в репозиторії; див.
[документацію Flutter](https://docs.flutter.dev/deployment/android#signing-the-app));
без нього — debug-ключем. Для швидкої розробки є й Linux-збірка: `flutter run -d linux`.

## Як це влаштовано

```
lib/
  discovery/    фоновий пошук принтерів (Android — NsdManager, інші ОС — mDNS) і пам'ять
  ipp/          мінімальний IPP: запити, відповіді, колекції; HTTP-транспорт
  printing/     можливості принтера, джерела (PDF, фото, колаж), макет, URF-кодувальник, конвеєр друку
  update/       перевірка й завантаження оновлень з GitHub-релізів
  ui/           список принтерів, аркуш друку, редактори макета й колажу, налаштування
android/…/MainActivity.kt  NsdManager, «Поділитися», Photo Picker, встановлення оновлень
```
