# KamiDrop 紙

[English](README.md) · **Українська**

Легкий локальний друк і сканування з Android — «як AirPrint»: без драйверів, акаунтів і хмари.
KamiDrop сам знаходить принтери у Wi-Fi мережі, друкує по IPP в AirPrint-растрі й сканує по eSCL (AirScan).

## Що вміє

- **Сам знаходить принтери й сканери** (mDNS / DNS-SD) і пам'ятає їх; принтер можна додати й за IP.
  Показує стан, колір / дуплекс / роздільність і рівні чорнила чи тонера.
- **Друкує PDF і фото**: превʼю зі стрічкою сторінок, вибір сторінок («3-5, 8»), колір, двосторонній друк,
  копії, скасування завдання.
- **Редактор макета**: орієнтація; вписати / заповнити / 100 %; точні розміри фото 9×13, 10×15, 13×18, A5
  з кадруванням; поля або друк «до краю» на принтерах, що це вміють. Що бачиш — те й друкується:
  розміри на папері перевірені лінійкою й сканером (1:1, сітка 10,0 мм).
- **Кілька фото на аркуші**: тягнути, масштабувати двома пальцями, повертати, точні розміри з обрізкою,
  подвійний тап — кадрування, тримай фото й свайпни іншим пальцем — на інший аркуш.
- **Сканування** зі скла або з подавача: кольорове, сіре чи чорно-біле, 75–600 dpi; зберегти як **PDF**
  (один файл), **JPEG** або **PNG**, поділитися чи одразу надрукувати (ксерокопія).
- **«Поділитися → KamiDrop»** з галереї, файлів чи будь-якого застосунку.
- **Сам оновлюється** з GitHub-релізів (перевірка раз на добу; встановлення — лише після натискання).
- **Українська й англійська** — за мовою системи або вибрана в налаштуваннях.

Потрібен принтер з AirPrint (більшість мережевих принтерів після ~2013 року) і телефон з Android 7+ у тій
самій Wi-Fi мережі. Для сканування — сканер з eSCL / AirScan (або шлюз на кшталт
[AirSane](https://github.com/SimulPiscator/AirSane) для сканерів без нього).

## Встановлення

1. Завантаж APK з [останнього релізу](https://github.com/4bit33/kamidrop/releases/latest):
   `kamidrop-…-arm64-v8a.apk` — для майже всіх сучасних телефонів.
2. Відкрий його на телефоні й дозволь встановлення з цього джерела.
3. Google Play Захист може попередити, що розробник не перевірений, — це нормально для застосунків
   не з Google Play. Натисни **«Усе одно встановити»**.

Далі KamiDrop сам підкаже, коли вийде нова версія.

## Як це влаштовано

Майже все написано на чистому Dart, без бібліотек для друку чи сканування:

| Частина | Що робить |
|---|---|
| `lib/ipp/` | Мінімальний **IPP**-клієнт (RFC 8010/8011): кодування запитів разом із колекціями (`media-col`), розбір відповідей, Print-Job, Get-Job-Attributes, Cancel-Job |
| `lib/printing/urf.dart` | Кодувальник/декодувальник **URF (Apple raster)** з PackBits, перевертання звороту при дуплексі |
| `lib/printing/compose.dart` | Макет сторінки в міліметрах, поля принтера з IPP, поворот, кадрування, sRGB / сірий |
| `lib/printing/collage.dart` | Аркуші з фото: рамки в мм, авторозкладка, кадрування (zoom/pan), складання в ізоляті |
| `lib/scan/escl.dart` | Клієнт сканування **eSCL**: можливості, багатосторінкові завдання з подавача |
| `lib/scan/pdf_writer.dart` | Маленький **генератор PDF**: JPEG сканера без перекодування, 1-бітні сторінки для чорно-білого |
| `lib/discovery/` | Пошук принтерів і сканерів: Android `NsdManager`, mDNS на інших ОС; пам'ять принтерів |
| `lib/update/` | Самооновлення з GitHub-релізів через Android `PackageInstaller` |

Якщо пишеш свій клієнт, зверни увагу на виловлені особливості заліза: наприклад, Brother DCP-J572DW
мовчки ігнорує налаштування eSCL-сканування, якщо в XML є переноси рядків, і зависає на chunked-тілі запиту.

## Збирання

Потрібен [Flutter](https://flutter.dev) (stable) і Android SDK.

```
flutter pub get
flutter test
flutter run                                   # на під'єднаний телефон
flutter build apk --release --split-per-abi   # release-APK
```

Release підписується ключем з `android/key.properties` (не в репозиторії; див.
[документацію Flutter](https://docs.flutter.dev/deployment/android#signing-the-app)); без нього —
debug-ключем. Для швидкої розробки є й Linux-збірка: `flutter run -d linux`.

Переклади — у `lib/l10n/app_uk.arb` (джерело) і `lib/l10n/app_en.arb`.
